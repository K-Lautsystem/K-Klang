# K-Lautsystem (K-Klang)

## K-Laut System – Grundregel

Grundregel: Deutsche Wörter werden mit Hangul-Lauten dargestellt, damit Aussprache international verständlich und einfach lernbar wird.

K-Laut verbindet Sprache, Klang und Schrift durch ein universelles phonetisches System.

## Neue Grundregel (Kurzfassung)

Deutsche Wörter werden mit Hangul-Lauten geschrieben, um Aussprache weltweit einfach und verständlich darzustellen.
